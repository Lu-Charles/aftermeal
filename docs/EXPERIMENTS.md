# Experiments

The segmentation comparison evaluates frozen mask features against appearance
and change baselines using the same grouped folds. LeFood error increased from
9.63 pp for Change to 15.82 pp for segmentation and 11.94 pp for combined features.
The deployed compact estimator is retained.

[Segmentation results](../reports/segmentation-experiment.json).

Visual proposals are review aids, not corrected source masses or evaluation labels.

[Depth and blend results](DEPTH.md) did not justify changing deployment weights.
