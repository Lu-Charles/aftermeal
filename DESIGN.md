# Interface

The main screen pairs before/after photographs with a single percentage estimate. Navigation has three views: Analyze, Accuracy and About.

## Analysis

Choosing a sample loads its result automatically. **Your photos** provides two upload targets and an **Analyze pair** button. Each uploaded image has a **Change photo** control; both file selection and drag-and-drop are supported.

The three gallery samples use dish names. The fourth pair appears in an Accuracy disclosure. Sample results include the recorded fraction and prediction error. A food-highlight toggle is available for sample photos.

Switching views preserves uploaded photos and their completed result. Replacing a photo clears the result, and stale responses are discarded. Reloading resets the workspace.

## Layout and controls

Photos remain paired on narrow screens. Technical details sit in disclosures below the result. Empty uploads have no result panel; status messages cover loading and recovery.

Tabs support arrow keys, Home and End. Focus indicators remain visible, and reduced-motion preferences disable transitions.

## Typography and color

The interface uses the system sans-serif stack. Body text is 17px; secondary controls use 14px; headings scale from 40px to 64px.
